# PomodoroTimerX

專為老師與學生而設的單頁蕃茄鐘：高對比大字、可投影、可離線（載入後）。

## 功能

- 25 / 5 / 15 分鐘標準蕃茄循環，可自訂專注、短休、長休與輪數
- 三種模式分頁（專注 / 短休 / 長休）、循環進度點、MM:SS ↔ HH:MM:SS 切換
- 大字倒數，剩餘 ≤ 60 秒自動轉紅並顯示「最後衝刺預警」
- 點擊大數字可精確編輯時 / 分 / 秒；左右 `- / +` 一鍵加減 1 分鐘
- 四個快速場景範本（批改、備課、自修、隨堂練習）
- 專注資訊卡（4×2）可調字型比例 100 / 115 / 130 / 150%
- 待辦任務清單，可勾選、切換當前任務、刪除
- 完成提示音：考場鐘聲 / 數碼提示 / 木琴和弦 / 靜音（Web Audio 即時合成，無外部檔案）
- 深淺色主題、介面字型放大縮小、全螢幕、隱藏工具列（H）
- 所有設定存於 `localStorage`，不會上傳

## 鍵盤快捷鍵

| 鍵 | 動作 |
| --- | --- |
| Space | 開始 / 暫停 |
| R | 重設當前時間 |
| S | 跳過當前階段 |
| H | 隱藏 / 顯示工具列 |
| F | 切換全螢幕 |
| 1 / 2 / 3 | 切換專注 / 短休 / 長休 |

## 本機執行

直接用瀏覽器打開 `index.html` 即可，不需要 build、不需要伺服器。

樣式用 Tailwind Play CDN、字型用 Google Fonts，所以第一次開啟需要網絡；之後瀏覽器會快取。

## 部署

這是一個靜態單頁，任何靜態主機都可以：

- **Netlify**：Import repo → Build command 留空 → Publish directory `.`（repo 內已附 `netlify.toml`）
- **GitHub Pages**：Settings → Pages → Deploy from branch → `main` / root

## 設計

沿用 ExamTimerX 的卡片語言：白色（深色模式為 #1E293B）卡片、#00A3FF 主色、#FF3B5C 重設色、Chakra Petch 等寬大字。
